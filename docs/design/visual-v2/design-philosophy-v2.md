# Court Margin v2 / 球场页边：证据有形，状态诚实

v2 仍把网球知识看作一本带上球场的工作手册，只是把 v1 里用气氛表达的几件事写成了规则：一句话依据什么，一条记录存在哪里，一个页面改了什么。深石墨、纸白和球场绿依旧是底色，金色依旧只落在品牌字标和向前的球路上。变化在于，最需要被看见的文字不再是页面上最淡的文字。v1 把“未经核验”“草稿只在本机”这类句子放在最低声量里，v2 把它们放到和元信息同一档，对比度不低于 4.5:1。

阅读仍然是主景。正文收窄到每行约 36 个汉字，17px、行高 1.8。来源不再是段落末尾的一块引用区，而是贴在句子后面的 S1、J7 标记。点开标记，证据栏里会出现这条来源的定位：媒介、时间段、快照版本、审阅时间，以及“原始视频 → 逐字稿 → 提炼稿”这条证据链。哪一环缺失，就在哪一环画断线，并注明来源信息待补。桌面上证据常驻右栏；手机上从底部抽屉打开，翻页和关闭都在拇指够得到的位置。

证据用四种方式同时编码：颜色、线型、标记字母、文字标签。资料支持就是正文加 S 标记，选中时加实线下划线，这是“组织过的”线；本人记录用点线和原话引号，像笔记本边上的手写批注；模型补充用虚线框，不带引用标记，这是“探索中的”线；待审阅的来源用空心点和斜纹，不进入正式回答。五大类目录也沿用这套语法：每一份来源画成一个点，实心、半实心、空心分别对应三种状态。这些点只表示有几份来源、处在什么状态，不代表质量评分。没有来源的主题画一道短横线，并写明“缺来源，不由模型补写”。

状态被拆成四段：本机草稿、已提交、Agent 整理、Wiki 更新，每一段单独报告。记录保存成功不等于提交成功，提交成功也不等于 Wiki 已经更新；任何一段失败，都不能被后一段的“成功”盖住。离线、未提交草稿数量、待审阅数量常驻在顶栏和标签角标里，不藏进菜单。技术 Wiki 的改动只以提案出现，审阅页先展示差异、冲突和发布前核对，再给出发布按钮；个人 Wiki 可以自动更新，但每次都能对照上一版、回退上一版，并声明原始记录一字未动。

同一套 token 服务两种光线：浅色是默认，适合球场上的日光；深色是可选的夜间阅读模式，延续 v1 A 稿的气质。精心打磨仍然体现在行长、基线、留白和细线的对齐上。五类目录的列线借用球场的边线与发球线，切削示意图只画拍头方向、过网高度和弧线，并标明“示意，非测量”。界面不出现可信度百分比、能力评分或效果提升数字。

## 与现有代码的对应

以下能力在现有数据契约里已经存在，v2 只是换了呈现方式：

- 证据类型：`Section.kind`（`source_supported` / `personal_observation` / `model_supplement`），`Evidence.kind`（`technical` / `journal`）。
- 页面与版本：`WikiDetail.status`（`draft` / `published` / `empty`）、`has_draft`、`index_status`，`WikiVersion.status`。
- 草稿与提交：本机草稿 `state`（`editable` / `locked`）、未保存输入（`dirty`）、服务端回执。
- Agent 运行：`Run.status`（`queued` / `running` / `succeeded` / `failed` / `needs_input`）。
- 服务状态：`agent_enabled`、`model_configured`、`pending_reviews`。

以下内容需要改后端或数据结构，不能只改样式：

1. **分类与多来源主题**：目前一份文件对应一个页面（`topic_key` 就是文件路径），没有五类字段，也没有“多份来源 → 一个主题”的编译层。目录里的主题划分是目标结构。
2. **来源登记字段**：作者 / 机构、媒介、时间段、许可范围、审阅时间目前没有系统保存；`source_url` 在文件导入时也没有填入。现有 15 篇正手资料都是 AI 提炼稿，有一篇的来源字段只是占位符。
3. **行内标记定位**：现有 `citation_ids` 挂在段落上，没有句内锚点和时间码，需要在 section 内增加 span 级引用，或改为“句子 → 引用”结构。
4. **差异视图**：现有版本面板展示整版内容，不计算段落级差异；“删除了有来源支持的说法”这类检查需要新增规则。
5. **运行来源展示**：需要在提案上保存并显示运行编号、读取了哪些来源、是否读取个人记录。

## 参考与原创边界

参考边界沿用 v1（见 `../visual-v1/design-philosophy.md`）：Readwise Reader 借鉴专注阅读与桌面 / 手机分工，TennisLevel 原型借鉴绿金色系与球路元素，训记借鉴轻量、细颗粒的记录，Tennis Notes 借鉴训练与反思的联系。本稿没有嵌入任何第三方截图、字体、图标或商标素材，所有示意图都是重新绘制的。

画布中的示例来源（“反手切削基础”“切削的使用情境”“正手切削”“示例频道”）都是占位，不对应真实教练、视频或出版物。切削技术要点只作界面样例，不是训练建议；训练编排与组数标为模型补充。
